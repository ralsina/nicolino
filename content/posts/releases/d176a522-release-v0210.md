New release [on Github](https://github.com/ralsina/nicolino/releases/tag/v0.21.0)

<!--more-->

<h3>🐛 Bug Fixes</h3>
<ul>
<li>Parallel builds no longer crash on large sites: croupier 0.13.0 fixes the Boehm GC segfaults in <code>_run_tasks_parallel</code> (19 consecutive cold parallel builds of a 4000-post site without a single crash, where croupier 0.12.4 segfaulted on the first attempt)</li>
</ul>
<h3>⚡ Performance</h3>
<ul>
<li>Parallel builds are now actually usable: ~4.7s vs ~14s serial for a 4000-post site</li>
</ul>
<h3>📦 Dependencies</h3>
<ul>
<li>croupier ~&gt; 0.13.0</li>
<li>Require Crystal &gt;= 1.20.0 (as croupier 0.13.0 does)</li>
</ul>
