New release [on Github](https://github.com/ralsina/nicolino/releases/tag/v0.25.0)

<!--more-->

<h3>🚀 Features</h3>
<ul>
<li>Server-side syntax highlighting for markdown code blocks via<br>
tartrazine (used by listings before, now everywhere): tz-prefixed<br>
CSS classes, css/syntax.css with dark/light variants derived from<br>
the site's color_scheme (or <code>syntax_theme:</code> override); opt out<br>
with <code>syntax_highlighter: none</code>; highlight.js CDN scripts dropped<br>
from all bundled themes</li>
<li>Translation fallback system (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5206037965" data-permission-text="Title is private" data-url="https://github.com/ralsina/nicolino/issues/54" data-hovercard-type="issue" data-hovercard-url="/ralsina/nicolino/issues/54/hovercard" href="https://github.com/ralsina/nicolino/issues/54">#54</a>): untranslated content is rendered<br>
from its default-language version (or any available translation),<br>
flagged with <code>is_fallback</code> in the post and page template contexts;<br>
disable with <code>content_fallback: false</code> in conf.yml</li>
<li>Site-level <code>language_links</code> helper shared by posts, index pages,<br>
taxonomy pages and page folder indexes, so translation-switcher<br>
menus work everywhere (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5206037965" data-permission-text="Title is private" data-url="https://github.com/ralsina/nicolino/issues/54" data-hovercard-type="issue" data-hovercard-url="/ralsina/nicolino/issues/54/hovercard" href="https://github.com/ralsina/nicolino/issues/54">#54</a>)</li>
<li>Theme parameters: theme.yml's <code>params:</code> section (plus metadata) is<br>
exposed to all templates as the <code>theme</code> variable; sites override<br>
values via conf.yml's <code>theme_params:</code> section</li>
<li>Terminal theme, ported from the Hugo theme by panr (MIT), with<br>
base16 color-scheme integration and a dark/light toggle</li>
<li>PaperMod theme, ported from the Hugo theme by adityatelange (MIT),<br>
with base16 palette and highlight.js token mapping</li>
<li>Index pages now render with site/theme constants in scope, so<br>
templates can use <code>site_*</code> and <code>theme.*</code> in index.tmpl</li>
<li>Theme registry: <code>nicolino theme install/list/remove</code> fetches themes<br>
from a remote registry (default <code>https://nicolino.ralsina.me/themes.json</code>),<br>
verifying each tarball's SHA256, so themes can be installed without<br>
cloning them into the repo by hand</li>
<li>Root-relative (and <code>url_prefix</code>-aware) link relativization: pages served<br>
under a subpath now rewrite <code>/css/style.css</code> links to correct relative<br>
paths, and the link checker resolves <code>..</code> from nested pages</li>
</ul>
<h3>🐛 Bug Fixes</h3>
<ul>
<li>Fix <code>remove_empty_paragraphs</code> deleting paragraphs that contain only<br>
an image (or any element without text), which made markdown images<br>
disappear from posts whenever the HTML filter pass ran</li>
<li>Template preprocessor folded <code>{% if %}</code> tags whose body was static<br>
without checking the condition, silently dropping branches that<br>
test runtime variables (e.g. <code>is_fallback</code>, <code>language_links</code>)</li>
</ul>
