## Installing a theme

Themes that ship with Nicolino (Default and Minimal) are available out of
the box. To use Terminal or PaperMod:

1. Copy the theme directory into your site's `themes/` folder:

   ```bash
   cp -r themes/terminal mysite/themes/terminal
   ```

2. Set the theme in `conf.yml`:

   ```yaml
   theme: terminal
   ```

3. Rebuild your site.

See the [Themes](/books/user-guide/themes.html) chapter of the User Guide for
full documentation on customizing and porting themes.
