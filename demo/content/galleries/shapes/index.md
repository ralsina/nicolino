---
title: "Geometric Shapes"
date: 2026-10-02
summary: "A four-image gallery so themes can show off their grid and lightbox."
---

Galleries are folders of images under `galleries/` with an `index.md`
like this one. Each theme renders the same folder as an image grid;
click any shape to open the lightbox view.

These four shapes are deliberately tiny PNGs: the point is to see how
the theme lays out a gallery — spacing, captions, hover states — not
to admire the artwork.
