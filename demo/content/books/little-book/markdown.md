# Markdown

The usual suspects work inside chapters:

- **Bold**, *italic* and `inline code`
- Lists, like this one
- [Links to other chapters](links.md), which end up as `.html` in
  the rendered book

Code blocks are highlighted with the site's base16 color scheme:

```crystal
def chapter_title
  "Chapter #{number}: #{title}"
end
```

> Blockquotes are handy for asides — every theme should set them
> apart from body text.
