# About This Book

This book exists so theme demos can show how a **book** looks, not
just a blog. A nicolino book is a folder under `books/` with a
`book.toml`, a `SUMMARY.md` listing its chapters, and the chapter
files themselves — the same layout mdbook uses.

Everything you see here is rendered by whatever theme the demo site
is currently wearing: the sidebar, the chapter numbers, the
breadcrumbs and the previous/next links all come from the theme's
`book_*` templates.
