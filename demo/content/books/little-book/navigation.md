# Chapters and Navigation

The `SUMMARY.md` file defines the chapter tree: flat entries become
numbered chapters, and indented entries become subsections.

This chapter is number 2. The next one has subsections 3.1 and 3.2,
so you can check that a theme nests them correctly in the sidebar and
numbers them in the page headers.

At the bottom of every chapter the theme should render **previous**,
**next** and **up** links, following the order in `SUMMARY.md` —
books are meant to be read linearly, and a theme that hides that
navigation is not much of a book theme.
