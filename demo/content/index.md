This site exists to show off **Nicolino themes** with a small amount
of realistic content:

- [A markdown tour](posts/markdown-tour.md) — headings, lists, quotes, tables
- [Code blocks](posts/code-blocks.md) — syntax-highlighted fences in several languages
- [Pictures and folded posts](posts/images-and-teasers.md) — an image, a summary and the fold

It is also **multilingual**: switch to `es` in the header to see the
language switcher, a translated post, and one post flagged as
untranslated via the `is_fallback` badge.

Toggle the color scheme with the ◐ button — both themes follow the
`gruvbox` base16 scheme set in `conf.yml`.
